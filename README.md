# HTML/CSS Website V1

A responsive and modern website template built to demonstrate frontend development skills using core web technologies. This project focuses on clean code structure, responsive layout, and interactive elements.

## 🚀 Features

* **Responsive Design:** optimized for desktop, tablet, and mobile viewing.
* **Modern UI/UX:** Clean interface with SVG imagery.
* **Multi-page Layout:** Includes specialized pages (e.g., Tech page).
* **Interactive Elements:** Powered by custom JavaScript (`app.js`).

## 🛠️ Technologies Used

* **HTML5:** For semantic content structure.
* **CSS3:** For styling and responsive layouts.
* **JavaScript:** For client-side logic and interactivity.
* **SVG:** Scalable vector graphics for high-quality visuals.
